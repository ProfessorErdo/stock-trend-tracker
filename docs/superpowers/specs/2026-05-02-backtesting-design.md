# 选股策略回测系统设计规范

## 1. 项目概述

### 1.1 策略逻辑
每周基于低估值（PE/PB/PR最低四分之一）与高ROE（最高四分之一）指标构建等权持仓，每周进行一次调仓。当入选股票过少时引入集中度控制，限制单只股票最大仓位20%并强制保留现金。

### 1.2 核心参数
- 初始资金：1,000,000 元
- 调仓频率：每周一次（截面日为周最后交易日，调仓日为截面日后下一交易日）
- 回测区间：2015-01-01 至最新交易日
- 股票池：沪深300 + 中证500 + 红利 + 红利低波 + 国证2000 + 国证自由现金流 + 中证自由现金流（约930只股票，去重）
- 基准：上述股票池等权组合，每周再平衡

## 5. 选股与调仓核心逻辑

### 5.1 每周选股流程（截面日执行）

```
步骤1: 基础过滤
├── 排除上市不足120天的股票
├── 排除当日停牌的股票（无行情数据）
└── 剔除 PE、PB、PR、ROE 为负或缺失的股票

步骤2: 估值分位数筛选
├── 对剩余股票进行 1%-99% winsorize（极值截尾）
├── 计算 PE_25p（25%分位数），保留 PE ≤ PE_25p 的股票
├── 计算 PB_25p，保留 PB ≤ PB_25p 的股票
├── 计算 PR_25p，保留 PR ≤ PR_25p 的股票
└── 取三个条件的交集 → 得到估值最低四分之一

步骤3: ROE筛选
├── 对步骤2结果计算 ROE_75p（75%分位数）
└── 仅保留 ROE ≥ ROE_75p 的股票 → 最终股票池

步骤4: 结果处理
├── 若 N = 0 → 本周空仓，全部持有现金
└── 若 N > 0 → 应用集中度控制规则
```

### 5.2 调仓执行流程（调仓日执行）

```
步骤1: 计算总权益
├── total_equity = 现金 + 持仓市值（用后复权收盘价）

步骤2: 生成卖出订单
├── 清仓不在新股票池中的股票
├── 检查涨跌停：跌停无法卖出则保留
└── 执行卖出，扣除印花税+佣金，更新现金

步骤3: 应用集中度规则计算目标市值
├── 若 N ≥ 5: 每股目标市值 = 可用现金 / N
└── 若 N < 5: 每股目标市值 = 0.2 × total_equity
               强制保留现金 = (1 - 0.2×N) × total_equity

步骤4: 生成买入订单
├── 检查涨跌停：涨停无法买入则跳过，资金保留为现金
├── 计算可买入股数（整手向下取整，100股/手）
├── 执行买入，扣除佣金，更新持仓和现金
└── 记录每笔交易详情
```

### 5.3 买入股数计算逻辑

```python
# 计算理论可买股数
target_amount = 可用现金 / N  (每股分配金额)
或 target_amount = 0.2 × total_equity  (集中度控制时)

# 计算可买股数（向下取整到100股）
raw_shares = target_amount / open_price
final_shares = floor(raw_shares / 100) × 100

# 剩余现金保留
actual_cost = final_shares × open_price
remaining_cash = available_cash - actual_cost - commission
```

**示例**：
- 可用现金 100,000 元，分配给5只股票，每股 20,000 元
- 开盘价 15.5 元
- 理论股数 = 20,000 / 15.5 = 1290.32 股
- 取整后 = floor(1290.32 / 100) × 100 = 1200 股
- 实际花费 = 1200 × 15.5 = 18,600 元
- 剩余现金 = 20,000 - 18,600 - 佣金 ≈ 1,372 元（保留）

**注**：卖出时不受整手限制，可卖出任意持仓股数。

### 5.4 涨跌停判断逻辑

```python
# 涨停判断（无法买入）
if open_price >= prev_close * (1 + limit_ratio - tolerance):
    and low_price >= prev_close * (1 + limit_ratio - tolerance):
    → 全天封死涨停，无法买入

# 跌停判断（无法卖出）
if open_price <= prev_close * (1 - limit_ratio + tolerance):
    and high_price <= prev_close * (1 - limit_ratio + tolerance):
    → 全天封死跌停，无法卖出
```

### 5.6 财报可用日期计算

根据报告期月份判断财报类型：
- **年报**（12月）：报告期 + 4个月（次年4月底可用）
- **半年报**（6月）：报告期 + 2个月（8月底可用）
- **季报**（3月/9月）：报告期 + 1个月可用

## 6. 交易日历与调仓日规则

### 6.1 交易日历构建

从数据集中提取所有有交易记录的日期（任意股票有行情即认为市场开放），剔除周末与节假日，生成交易日列表 `all_trading_days`。

### 6.2 截面日确定

对于每个日历周（周一至周日）：
- 取该周内最晚的一个交易日作为截面日
- 若该周无交易日（整周休市），则不产生截面，不进行选股和调仓

### 6.3 调仓日确定

对于每个有效的截面日 D_cut：
- 查找 D_cut 在交易日列表中的下一个交易日，记为 D_rebalance
- 若 D_cut 已是交易日列表最后一天，则无后续调仓

### 6.4 特殊情况处理示例

1. **正常情况**：周五有交易 → 截面日=周五，调仓日=下周一
2. **周五休市**：周四为截面日，调仓日=下周一（若周一有交易）
3. **周一休市**：调仓日改为下周二
4. **整周休市**：本周不产生截面，不调仓，持仓保持不变

## 7. 绩效指标与可视化

### 7.1 绩效指标计算表

| 指标 | 计算方法 |
|------|----------|
| 累计收益率 | 期末总权益 / 初始资金 - 1 |
| 年化收益率 | (1 + 累计收益率)^(252/交易天数) - 1 |
| 年化波动率 | 日收益率标准差 × √252 |
| 夏普比率 | (年化收益率 - 2%) / 年化波动率 |
| 最大回撤 | max(净值峰值到后续谷底的跌幅) |
| 回撤持续天数 | 从峰值到谷底的天数 + 恢复天数 |
| 胜率 | 盈利调仓周期数 / 总调仓周期数 |
| 盈亏比 | 平均盈利周收益 / 平均亏损周收益（绝对值） |
| 平均周换手率 | ((买入额+卖出额)/2) / 调仓前总权益，求历次均值 |
| 超额收益率 | 策略累计收益 - 基准累计收益 |
| 跟踪误差 | 超额收益日收益率标准差 × √252 |
| 信息比率 | 超额年化收益 / 跟踪误差 |
| 分年度收益 | 各自然年收益率列表 |

## 8. 边界情况与错误处理

### 8.1 边界情况处理

| 场景 | 处理方式 |
|------|----------|
| 整周休市 | 该周不产生截面日，不调仓，持仓保持不变 |
| 截面日数据缺失 | 跳过该股票；大量缺失则记录警告 |
| 调仓日停牌 | 无法买入→资金保留现金；无法卖出→保留持仓 |
| 涨跌停封死 | 涨停无法买入→资金保留；跌停无法卖出→保留持仓 |
| 股票池为空（N=0） | 本周空仓，全部持有现金 |
| N < 5 集中度控制 | 单股最大20%仓位，强制保留 (1-0.2N) 现金 |
| 被动超仓 | 因跌停无法卖出导致超仓，下一窗口优先减仓 |
| 新股上市 | 排除上市不足120交易日的股票 |
| 财报未披露 | 使用最近可用财报；无可用财报则跳过 |
| API失败 | 重试机制（最多20次），记录失败股票 |

### 8.2 数据质量校验

```python
# 价格数据校验
- 检查 open/high/low/close 是否为有效正数
- 检查 high ≥ low, high ≥ open/close, low ≤ open/close
- 检查 volume 是否为非负数

# 财务数据校验
- roe_ttm 合理范围：-100% ~ 100%（超出则剔除）

# 估值指标校验
- PE/PB/PR 必须为正数才参与筛选
- 负值或缺失直接剔除
```
